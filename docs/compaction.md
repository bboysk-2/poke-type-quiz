# セッションのコンパクション

長い会話履歴は古い試行錯誤や読んだファイルの残骸でノイズになる。**状態はファイルに、会話は使い捨て**にする。

## 状態として残すもの（`pnpm compact` が生成）
- ゴール、現在のタスクと承認者
- 残りの手順・未確認の受け入れ基準
- 直近の verify 結果と主要な指摘
- メモ（`pnpm progress note` で残した決定事項・ハマりどころ）
- git の作業ツリーと直近コミット

## 残さないもの
会話のやりとり、読んだファイルの中身、試して捨てた案（必要なら note に 1 行で残す）。

## 手順
- **手動**: 区切りの良いところ（ステップ完了時、verify 通過時、コンテキストが重くなったと感じたとき）で
  `pnpm compact` → `/clear`。SessionStart フックが要約を注入し、クリーンな状態で再開する。
- **自動**: Claude Code の自動圧縮の直前に PreCompact フックが要約を保存し、圧縮後の SessionStart で再注入する。
- **目安**: 1 タスク = 1 セッション。タスクを done にしたら `/clear` して次へ。
